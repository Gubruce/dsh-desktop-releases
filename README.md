# DeepSeek Harness Desktop

[English](README.en.md) | 简体中文

> ⚠️ **非官方项目**：基于开源 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（dsh，AI Agent 运行时）的社区 Windows 桌面外壳，与 DeepSeek 官方无隶属关系。

把 **AI Agent 桌面化**：无需 Node.js、无需命令行，内置官方内核与运行时，**双击即用**的 Windows 应用。

**Agent 的核心卖点，全都开箱即用：**
- 🧠 基于官方 **DeepSeek Harness Agent 运行时**：工具调用 / 插件生态 / 长上下文
- 🤖 一个内核 = 多场景 Agent：对话、自动化任务、定时执行、长期记忆
- 🧩 插件市场可扩展：装社区插件即可获得更多能力（如**多智能体团队协作**，作者适配内核后将自动补装）

## ✨ 特性一览

**基础体验**
- 🚀 双击即用：自动拉起内核、自动关干净（无残留后台进程）；中文报错兜底（原因 + 查看日志 / 重试）
- 🧩 出厂预装：任务看板（task-board）+ 插件市场（dshmarket）

**内置增强（0.2.x）**
- 📅 **定时任务**：每日 / 每周 / 间隔自动执行 Agent 问答，睡眠自动跳过补跑
- 🧠 **长期记忆**：外壳侧记忆，喂给定时任务等发起的问答
- 📱 **手机远程访问**：同一 Wi-Fi 扫码直连；外出用免费公网临时隧道（带访问令牌，长时间无访问自动关闭）
- 🛡️ **三层插件防线**：插件哨兵 → 自动隔离重启 → 兼容矩阵，装了不兼容插件也不易拖垮启动
- 🔄 **自动更新**：发现新版自动提示，一键重启安装
- 💾 **数据安全**：崩溃自愈 / 数据目录锁 / 数据备份 / 数据健康体检 / 端口记忆
- 🖥️ **托盘 + 快捷键**：`Ctrl+Alt+D` 显示隐藏、`Ctrl+Alt+R` 重启服务

## 🚀 首次使用

1. 双击打开，等窗口弹出（一般 3~10 秒，首次自动初始化插件）
2. 在「**设置 → 模型**」填入你的模型供应商 API Key（DeepSeek 官方或兼容 OpenAI 的均可）
3. 开聊 / 使用 Agent；也可到「设置 → 通用设置」开启 **手机远程访问**、**定时任务 / 长期记忆** 等增强

![在设置中填入模型 API Key](assets/models.png)

## 🔄 更新方式

- **自动**：启动 20 秒后静默检查，发现新版弹提示下载（安装版支持一键重启安装）
- **手动**：托盘 →「检查更新…」；或下载新版安装包覆盖（数据不丢）

## 🔐 数据与隐私

- 数据目录 `~/.dsh`：会话 / 配置 / 插件 / 长期记忆 / 定时任务
- 模型 API Key 存于 `~/.dsh\.credentials.yaml`——**勿将该目录上传网盘或公开分享**
- 卸载应用**不会**删 `~/.dsh`（如需清数据请手动删除）
- 软件内"备份数据"会提示：备份含明文密钥，请加密留存

## ❓ 常见问题（FAQ）

**开始之前**
| 问题 | 回答 |
|---|---|
| 需要付费 / 下载收费吗？ | 软件免费；**模型 API Key 自备**（DeepSeek 官方或兼容 OpenAI 的服务商），费用按各家模型计 |
| 需要显卡 / 高配电脑吗？ | 不需要。所有推理走云端模型 API，本机只跑轻量桌面壳 |
| 和 DeepSeek 官方什么关系？ | 无隶属。官方内核开源（MIT / BSD-3），本仓库是社区外壳 + 发布通道 |

**使用中**
| 问题 | 回答 |
|---|---|
| 首次运行报"未知发布者" | 正常（未签名）；确认来源后「仍要运行」 |
| 会话会丢吗 / 数据在哪 | 存 `~/.dsh`；升级重装不丢 |
| 手机扫码连不上局域网 | 允许 Windows 防火墙弹窗；手机与本机同一 Wi-Fi |
| 怎么检查更新 | 托盘「检查更新…」；或启动后 20 秒自动静默检查 |
| 系统托盘不见了 | 托盘菜单「打开」恢复窗口；或 Ctrl+Alt+D |

**插件**
| 问题 | 回答 |
|---|---|
| 装了插件/主题后启动失败 | dsh 一个插件加载失败会拖垮启动；外壳已内置三层防线自动隔离并弹窗。仍失败可从托盘「被隔离的插件」查看或手动移除 |
| agent-teams 插件为什么没有 | 作者暂未适配当前内核；发布兼容版后会自动补装 |
